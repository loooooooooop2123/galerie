# Cimaise

Galerie d'art minimaliste : huit tableaux à parcourir d'un glissement (souris, doigt, clavier ou molette).
Le tableau actif est net au centre, ses voisins plus petits et légèrement flous. Sous chaque œuvre,
la vraie signature de l'artiste, une description et le cartel du musée.

Aucune dépendance : ouvrir `index.html`, ou servir le dossier tel quel.

## Sources
